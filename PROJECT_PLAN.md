# CineBook – Movie Ticket Booking Platform

## Project Objective
Build a full-stack movie ticket booking platform inspired by BookMyShow.

## Technology Stack

### Frontend
- Angular
- TypeScript
- Bootstrap

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven

### Database and Caching
- MySQL
- Redis

### DevOps
- Git and GitHub
- Docker
- Docker Compose
- Jenkins or GitHub Actions

## Architecture
Modular Monolithic Architecture with layered separation inside each business module.

## Main Business Modules
1. User Management
2. Movie Management
3. Theatre Management
4. Screen and Seat Management
5. Show Management
6. Booking Management
7. Payment Management
8. Notification Management

## Deployment Goal
Deploy Angular frontend, Spring Boot backend, MySQL and Redis using cloud hosting and containerization.

## Future Enhancement
Migrate selected business modules into independently deployable microservices.
